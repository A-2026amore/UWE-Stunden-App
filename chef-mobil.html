Zugänge vom Handy erstellen

Auf einem einmalig eingerichteten Chef-Gerät genügt künftig dein Chef-Passwort. Die private Sicherung bleibt auf Wunsch verschlüsselt auf diesem Gerät gespeichert; weder Chef-Passwort noch entschlüsselter Schlüssel werden dauerhaft abgelegt.

Wichtig: Gib die Chef-Sicherung niemals an Mitarbeiter weiter. Aktiviere „Dieses Gerät merken“ nur auf einem eigenen, gesperrten PC oder Handy. Die hinterlegte Sicherung bleibt verschlüsselt, kann aber von Software mit Zugriff auf dieses Browserprofil ausgelesen werden.

1. Chef-Verwaltung entsperren

Sicherer Chef-Zugang wird geprüft …

Beim ersten Mal auf PC oder Handy einmal die verschlüsselte Chef-Sicherung auswählen. Danach reicht auf diesem Gerät das Chef-Passwort, wenn du es unten als Chef-Gerät speicherst.

Im Testmodus kannst du die Chef-Oberfläche bedienen. Das Erstellen gültiger Mitarbeiterzugänge ist aus Sicherheitsgründen gesperrt.

Die App prüft, ob deine Sicherung zum öffentlichen Schlüssel deiner veröffentlichten Mitarbeiter-App gehört.

2. Mitarbeiterzugang erstellen

Für echte Mitarbeiterzugänge musst du später deine Chef-Sicherung und dein Chef-Passwort importieren.

Einzelzugang verschicken

Versende den Einladungslink an den Mitarbeiter. Die PIN bitte separat mitteilen. Erster Aufruf des Links öffnet die Mitarbeiter-Anmeldung.

WhatsApp öffnet eine vorformulierte Einladung. Kontrolliere den Empfänger und tippe dort auf Senden. Die PIN wird nicht mitgesendet.

PIN getrennt vom Einladungslink mitteilen. Nach dem Sperren der Verwaltung wird sie nicht mehr angezeigt.

3. Mehrere Mitarbeiter hinzufügen

Jede Zeile: Name;Personalnummer;PIN;WhatsApp-Nummer. Die PIN kannst du selbst festlegen (6–12 Ziffern). Lässt du sie weg, erzeugt die App automatisch eine zufällige neunstellige PIN. Die Namen und PINs werden nur auf deinem Gerät verarbeitet, nicht auf GitHub gespeichert.

Für jeden Mitarbeiter entsteht ein eigener signierter Zugang. Nach dem Erstellen kannst du die Einladungslinks per WhatsApp vorbereiten und die PINs getrennt mitteilen. Bitte versende die PIN nicht zusammen mit dem Einladungslink.

Im Testmodus lassen sich keine echten Mitarbeiter freischalten. Bitte die Chef-Sicherung mit Passwort entsperren.

Erstellte Zugänge

Diese Angaben verschwinden, sobald du die Verwaltung sperrst oder die Seite verlässt. Stelle sicher, dass jeder Mitarbeiter seinen Link und seine PIN erhalten hat.

4. Mitarbeiter verwalten

Hier siehst du die in dieser Chef-App erfassten Mitarbeiter und ihre Zugangsstatus. Neue Zugänge werden künftig automatisch in einer verschlüsselten Liste auf diesem Gerät gespeichert. Bereits früher angelegte Mitarbeiter bitte einmalig unten nachtragen.

Vorhandene Mitarbeiter ergänzen

Für Mitarbeiter, die schon vor dieser Funktion freigeschaltet wurden. Pro Zeile Name;Personalnummer;Gültig-bis (optional). Verwende die tatsächliche Personalnummer des bestehenden Zugangs; hier werden keine neuen PINs oder Links erzeugt.

Zugänge wirksam sperren

Wichtig: Eine echte Sperre muss online auf GitHub veröffentlicht werden. Nur das Anzeigen von „Gesperrt“ auf diesem Handy würde nichts bewirken. Die Mitarbeiter-App prüft den zentralen Status beim Anmelden und bei weiterer Nutzung mit Internetverbindung.

Für den grünen Sperren-Button wird einmal pro Sitzung ein GitHub-Token benötigt. GitHub: Fine-grained Token erstellen, Repository A-2026amore/UWE-Stunden-App, Berechtigung Contents: Read and write. Token und Chef-Passwort werden nicht auf GitHub veröffentlicht und nicht im Browser gespeichert. Das Token verleiht Schreibrechte auf das Repository; behandle es wie ein Passwort und nutze ein kurzes Ablaufdatum.

Die Veröffentlichung kann einige Minuten dauern. Eine zuverlässige sofortige Sperre auf einem offline betriebenen oder nicht aktualisierten Gerät ist technisch nicht garantiert.
